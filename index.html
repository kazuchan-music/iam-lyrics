    イェーイ！！

    歌詞に登場するイニシャリズム（略語）解説

    • NFC近距離無線通信技術（Near Field Communication）の略。スマホのタッチ決済や改札のピッと通る仕組みなどに使われています。
    • BPM楽曲のテンポを表す単位（Beats Per Minute）。1分間に刻む拍の数を意味します。
    • SNSソーシャル・ネットワーキング・サービス（Social Networking Service）。
    • DIY自分で何かを作ったり修理したりすること（Do It Yourself）。
    • PYT「Pretty Young Thing」の略で、キュートで素敵な人を指すスラング。マイケル・ジャクソンのシングルのタイトルとしても有名。
    • TKG日本のソウルフード「たまごかけごはん（Tamago Kake Gohan）」の略。
    • CEO最高経営責任者（Chief Executive Officer）。
    • APIソフトウェア同士を繋ぐインターフェース（Application Programming Interface）。
    • CPUコンピュータの中核となる中央処理装置（Central Processing Unit）。
    • GPS全地球測位システム（Global Positioning System）。
    • USB周辺機器を接続する汎用インターフェース規格（Universal Serial Bus）。
    • URLネット上の住所を示す識別子（Uniform Resource Locator）。
    • ATM現金自動預払機（Automated Teller Machine）。人生においてやっぱり大事な場所💴
